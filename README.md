# EV3Project2025

## 🔧 Project Description
This project is part of the Applied Application Project. The goal is to control a LEGO EV3 robot using Java. The development is managed using GitHub to ensure collaborative, organized, and version-controlled code.

## 🌱 Branch Structure

- **main** – Stable base of the project.
- **robot** – Contains basic movement functionalities for the robot.
- **speed** – Built on top of `robot`, adds speed control features.

---

## 🧠 Features

- Basic movement (forward, stop)
- Speed adjustment (in `speed` branch)
